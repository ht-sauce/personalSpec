## 如何使用

在新项目中对 AI 说：

> 把《通用项目建项规范-SPEC.md》通读一遍，按这份规范帮我立项（项目形态是 A 代码工程 / B 内容生成 / C 工作流搭建 / D 原型设计）

AI 通读通用骨架（形态 A / D 附对应接入件）→ 只问未明确的范围与验收 → 汇总结论供确认 → 建立最小入口、规范与地图；领域文档按需增加，不强制独立纪要。

## 维护

- 规范使用中发现新约束或流程改进 → 回填对应 SPEC 并在修订记录留痕（详见 [AGENTS.md](AGENTS.md) §7）。
- 本项目自身的治理文档在 [docs/](docs/)。
