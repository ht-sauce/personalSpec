# docs/README · personalSpec 项目治理入口

> 本文件管规范资产库的维护；通用规则归根目录主模板，形态差异归对应接入件。

## 1. 必读流程

先读 [AGENTS.md](../AGENTS.md) 与本文件；定位查 [project-overview.md](project-overview.md)。修改产品 SPEC 时读对应全文与 [writing-conventions.md](writing-conventions.md)，相关接入件按影响范围加读。

已确认的精简或修改按主模板 §3 执行：明确小改动直接修改与验证，架构 / 高风险 / 不明确事项先确认；允许增量修改和验证。

## 2. 核心护栏

1. **通用护栏适用本库**：遵守[主模板 §0、§2、§3](../通用项目建项规范-SPEC.md)，包括职责边界、先读再改、不扩范围、不一致先裁决、危险操作授权、5 分钟无进展检查点与验证证据；规则全文只在主模板维护。
2. **规则唯一归属**：通用规则写主模板，形态专属规则写接入件；入口只引用，禁止复制全文。
3. **必要同步**：章节、路径、版本或用途变化时，同批修正受影响引用与索引，范围见 §3。
4. **历史保留**：产品 SPEC 每次修改留版本、日期、要点；历史修订分析只增不删，否决与 superseded ADR 的清理须用户确认。
5. **不擅自建文档或提交**：未经明确要求不新增文档、不提交、不 push；Git 细则见[提交规则](../.trae/rules/git-commit-message.md)。

## 3. 维护契约

| 变化 | 同步归属 |
| --- | --- |
| 主模板章节 / 结构 / 版本 | 受影响接入件与附录引用、AGENTS / README / 文件地图 |
| 接入件内容 / 版本 | 接入件修订记录、受影响主模板引用与索引 |
| 规则 / 问项变化 | 对应 SPEC 修订记录 |
| 文件增删 / 用途变化 | 文件地图 |
| Git 规则变化 | 提交规则与主模板 §4 |
